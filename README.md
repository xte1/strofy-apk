# STROFY (Android)

تطبيق موسيقى بواجهة عربية كاملة (RTL) — المنطقة: العراق — صنع في العراق 🇮🇶

## بناء ملف APK
**الطريقة 1 – GitHub (بدون حاسوب):**
1. أنشئ مستودعاً على GitHub وارفع محتويات هذا المجلد.
2. تبويب Actions ← "Build STROFY APK" ← Run workflow.
3. بعد دقائق نزّل الملف من Artifacts باسم `STROFY-apk`.

**الطريقة 2 – Android Studio:** افتح المجلد ثم Build ← Build APK(s).
